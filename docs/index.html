Built for both sides of a campaign

A full-stack ASP.NET Core marketplace with real payment integration, e-signature agreements, and role-specific dashboards.

🏢

For Brands

Create campaigns with milestones and budgets, review applicants, message influencers, and release payments once proof of posting is approved.

✨

For Influencers

Discover campaigns, apply with a pitch, sign agreements, submit proof of work per milestone, and withdraw earnings to bKash, Nagad, or a bank account.

🛡️

For Admins

Review disputed milestones, verify accounts, process manual payouts, and track platform commission revenue from a dedicated wallet dashboard.

One campaign, start to finish

Every stage of a collaboration is tracked in the app — nothing happens off the record.

Campaign Created→ Influencer Applies→ Agreement Signed→ Milestones→ Proof Approved→ Payment Released→ Wallet Withdrawal

Real integrations, not mockups

Payments, media, and identity all run through genuine third-party services.

💳

bKash & Nagad Checkout

Server-verified payment gateway integration — brands pay through a real hosted checkout, and the callback is independently confirmed before any milestone is marked paid.

✍️

Campaign Collaboration Agreements

A signed e-agreement — drawn, typed, or uploaded signature — sits between an accepted application and an active collaboration, with a full audit trail.

☁️

Cloudinary Media

Every upload — campaign creatives, proof of posting, profile photos, signatures — is stored on Cloudinary, not local disk, so it's reliable across deployments.

🔐

ASP.NET Core Identity

Role-based auth for Brands, Influencers, and Admins, with email verification and password reset built in.

Tech Stack

ASP.NET Core MVC (.NET) Entity Framework Core PostgreSQL (Supabase) Razor Views Cloudinary bKash Tokenized Checkout Nagad Checkout ASP.NET Core Identity
